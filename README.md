# Saigon Now

ホーチミン（ベトナム）の **渋滞・雨雲レーダー・バイクの道順** をひと目で見るWebアプリです。
スマホのブラウザで開いて「ホーム画面に追加」すると、アプリとして使えます。

- Google マップの経路検索のように「出発」と「行き先」を入れると、ルートが出る（出発は空なら現在地。入力中に候補も出る。見つからないときは Google マップで探して URL を貼れる）
- 「いまの状況」で、渋滞（時間帯と雨からの目安＋Google マップの渋滞表示へ）・事故/通行止め（ニュースから。ルート上なら赤）・雨/冠水 をひと目で
- 「家」「会社」を登録しておくと、ボタン1つで現在地からのルートが出る（登録はその端末の中だけ）
- いま／これから1時間ごとの雨と渋滞の目安、おすすめの出発時刻
- 雨雲レーダー（Windy のような色のグラデーション、1時間先までの予測つき）。地図は昼は明るく、夜は暗く切り替わる
- 時間（今・14時・15時…）を押すと、その時の雨雲を地図に出す（1時間先まではレーダーからの予測、その先は5つの予報モデルの平均）
- バイクの道順（路地も使う）と、沿道にある市の交通カメラの映像
- 交通・天気ニュース（VOH と SGGP の最新記事から、事故・渋滞・通行止め・冠水・雨の記事を自動で拾い、札を付けて出す。10分ごとに更新）。いちばん早い VOH 交通ラジオ（FM95.6）へのリンクつき
- 表示の言語は 日本語・Tiếng Việt・English から選べる（右上）。日本語・英語ではニュースの見出しと要約を自動翻訳

## 位置情報と履歴について

現在地は、ルートと天気を調べるときにだけ使い、どこにも保存しません。
検索した行き先の履歴（最近の行き先）、登録した家・会社、選んだ言語、ニュースの訳は、その端末のブラウザの中（localStorage）にだけ保存されます。
道順と天気を調べるときに、位置だけを下記の地図・天気のサービスに送ります。翻訳サービスに送るのはニュースの見出しと要約だけです。

## 使っているデータ（すべてキー不要の公開サービス）

- 天気予報・先の時間の雨の地図：[Open-Meteo](https://open-meteo.com/)（ECMWF・GFS・ICON・UKMO・GEM）
- 雨雲レーダー：[RainViewer](https://www.rainviewer.com/)（1時間先の予測はこのアプリ内で計算）
- 交通カメラ：[ホーチミン市 交通情報ポータル](https://giaothong.hochiminhcity.gov.vn/)
- 道順：[OpenStreetMap](https://www.openstreetmap.org/copyright)（バイク＝FOSSGIS の自転車向け道順、大通り＝OSRM）
- 場所の検索：[Photon](https://photon.komoot.io/)（OpenStreetMap）
- 地図：Esri（雨雲の地図は昼＝Light Gray Canvas・夜＝Dark Gray Canvas、市内6エリアは World Street Map）
- 交通・天気ニュース：[VOH（ホーチミン市の放送局）](https://voh.com.vn/) の「交通」「天気」と、[SGGP（サイゴン解放新聞）](https://www.sggp.org.vn/) の RSS（天気が少ないときは SGGP 英語版の Weather 欄で補う）
- ニュースの自動翻訳：[MyMemory](https://mymemory.translated.net/)（無料の範囲。1日の上限に達した日は元の言葉のまま表示）

渋滞は時間帯と雨からの目安です。実際の混み具合はカメラ映像や Google マップで確かめてください。
